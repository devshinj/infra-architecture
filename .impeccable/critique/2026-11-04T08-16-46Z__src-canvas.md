## Design specificity
LLM: 제품에 맞춘 디자인 — 선 종류를 모양으로 구분하고 강조 중에도 유지, 영역 종류별 색조, 단계 흐림(선 12%·노드 18%·영역 35%). 겉 한 겹(유리 패널·금색 강조·남색)은 흔한 다크 SaaS. 강조색(-lit)이 거의 흰색으로 모여 종류별 색 성격이 강조 순간 사라짐.
Detector: CLI `detect src/canvas` 0건. Browser(headless, 오버레이 사람 탭 없음): 채팅 입력 placeholder 대비 부족(캔버스 밖), 상세 패널 글자 위계 평평(캔버스 밖), nested-cards(React Flow 구조 — 오탐), 선택 중 1.9:1 low-contrast(흐린 노드 글자로 추정 — 의도된 디밍).

## What's working
1. 단계 흐림이 맥락을 지우지 않고 초점을 줌(전체 보기에서 특히 강함). 호버는 한 단계 약해 선택과 구분됨.
2. 선 종류 모양이 강조돼도 유지(비동기 점선·관리 점점선·복제 겹선) — 색만으로 뜻 전달 안 함.
3. 영역 이름표가 선 위 불투명 알약 — 선이 이름을 긋지 않음.

## Priority issues
- [P1] 허브 노드의 ×N 이름이 서로·노드와 겹침 (ALB: "HTTP 80 ×4"+"HTTP 8080 ×2" 같은 자리, API #1 "HTTPS ×3" 노드 테두리에 닿음). Fix: 같은 변에 묶음 2개 이상이면 줄 단위로 쌓고, 글자 상자와 노드(+선택 링 4px) 겹침 검사 후 밀어내기, 시각 회귀 기준선. → /impeccable harden, /impeccable layout
- [P1] 확대 보정된 영역 이름이 전체 보기(배율 0.36)에서 말줄임("Mgmt Subnet", "문자 발···")·노드 이름보다 커 위계 역전; 접힌 상자 폭은 11px 기준이라 20px에서 다시 잘림. Fix: 접힌 폭을 실제 최대 글자로, 상한을 노드 이름 화면 크기 기준으로 묶기, 접기 단추도 같은 규칙. → /impeccable typeset
- [P2] 카메라가 고른 대상·패널 여백을 챙기지 않음(첫 화면 왼쪽이 사이드바 밑, 고르면 이어진 끝이 화면 밖, 폰 전체 보기 잘림). Fix: inset 지키는 맞춤, 고르면 이어진 끝까지 보이게 이동 또는 "화면 밖 연결 N개" 표시. → /impeccable adapt
- [P2] 강조색이 거의 흰색으로 모이고, 금색 흐름 조각이 선택 중에도 흐린 선 위에 남아 선택과 다툼. Fix: -lit 채도 유지·명도만 올림, 선택 중 이어지지 않은 선 움직임 정지, 흐름 표시 기본값 재검토. → /impeccable colorize, /impeccable quieter
- [P3] 기본 배율에서 선 이름·보조 글자 화면 약 7.9px, ×N 뜻 설명 없음. Fix: 선 이름도 화면 최소 크기 보정, ×N에 대상 목록 말풍선 또는 "HTTPS · 3곳". → /impeccable clarify
