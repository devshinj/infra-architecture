# 영역 선택과 영역 설명

날짜: 2026-11-13. 브랜치 `feat/group-select`.

## 왜

영역(코드 이름 group, 화면 이름 영역)은 지금 고를 수 없다. 바탕이나 이름 알약을 누르면 선택이 풀린다(10/30 "다시 누르면 선택 해제"). 설명 탭의 영역 화면(`NodeInfo`)은 이름·종류·링크 단추뿐이고, 열 길도 없다. 11/06 망 종류 설계 때 "영역 정보 패널은 새로 만들지 않는다"고 미뤄 둔 것을 이번에 연다.

## 정한 것

### 고르기 (사용자)

- 영역 **이름 알약**을 누르면 그 영역을 고른다. 이미 고른 영역의 알약을 다시 누르면 푼다.
- 영역 **바탕**을 누르면 지금처럼 선택을 푼다. 리전 영역이 캔버스를 다 덮어도 풀 곳이 남는다.
- 키보드: 영역에 포커스를 두고 **Enter** 는 고르기(다시 누르면 풀기), **Space** 는 지금처럼 접기·펴기.
- 고르면 노드와 같이 설명 탭이 열린다. 영역 테두리에 이미 있는 선택 표시(`group--selected`)를 쓴다.

### 설명 탭 (사용자)

차례대로:

1. 머리: 이름, 종류, 링크 복사.
2. **망 종류** (망 영역만): 붙은 망 종류 이름·등급·망 지식 설명 한 줄. AI 가 붙이고 아직 확인하지 않았으면 "AI 추정" 표시. 바꾸기·확인은 지금처럼 채워야 할 정보에서 한다.
3. **AI 설명**: 이 구성에서의 역할, 경계에서 드나드는 것, 자세히(정의·필요한 이유·비교·왜 이렇게 짰나요).
4. **안에 든 것**: 바로 안의 노드와 하위 영역 칩. 누르면 그것을 고른다.
5. **경계를 넘는 연결**: 영역 안(자기 포함)과 밖을 잇는 연결. 줄마다 ←/→, 안쪽 끝 이름, 바깥 끝 이름, 연결 종류·라벨. 줄을 누르면 그 연결을 고른다.
6. **이 영역에 대해 물어보기**.

### AI 설명 (사용자)

- 모양: `{ kind: "group", 정의 부분, role, boundary, adr }`. 정의 부분(term·definition·출처·why·compare)은 노드와 같다.
  - role: 이 구성에서 이 영역이 맡은 일, 150자.
  - boundary: 경계에서 무엇을 들이고 무엇을 막는지, 어떤 연결이 넘나드는지, 150자.
  - adr: 결정·이유·대안·대가 각 80자.
- **영역을 고를 때만** 만든다(연결과 같다). 화면을 열 때 미리 만들지 않는다.
- 캐시 서명: 종류·이름·망 종류 + 바로 안의 항목(종류·이름) + 경계를 넘는 연결(종류·방향·바깥 끝). 안이나 경계가 바뀌면 낡은 설명이 된다.
- 품질 검사(길이 상한, Clef 쉬움 점수, 최대 2회 다시 쓰기)와 다시 쓰기·다시 시도는 노드와 같다.

### 사전 용어 (제 판단)

영역 용어 후보는 영역 이름 → 종류 용어 순이다. 종류 용어는 사전 seed 에 있는 말로 맞춘다.

| 종류 | 용어 |
|---|---|
| cloud_region | 리전 |
| vpc | VPC |
| subnet_public, subnet_private | 서브넷 |
| dmz | DMZ |
| idc | IDC |
| onprem_zone | 온프레미스 |
| k8s_cluster | 쿠버네티스 |
| redundancy_group | 이중화 |
| network_zone | 망 |
| external_service | 외부 서비스 |

- 이름에서 온 후보는 노드의 sub 처럼 사전에 넣지 않는다(이름이 용어가 아닐 수 있다).
- 사전에 없는 종류 용어는 노드처럼 AI 정의를 미검수로 사전에 넣는다(분류 "영역").

### 물어보기 (제 판단)

- 노드 질문 세션(`chat_sessions.kind = 'node'`)을 그대로 쓰고 `node_id` 에 영역 id 를 넣는다. DB 를 바꾸지 않는다.
- 서버는 대상이 노드나 영역이면 받는다. 프롬프트는 대상이 영역이면 "대상 영역" 요약과 영역 설명을 근거로 준다.
- 세션 목록·대화 머리의 이름은 노드나 영역의 지금 이름이다. 둘 다 없으면 지금처럼 "(지워짐)".

## 안 하는 것

- 영역 경고(주의할 점): 경고는 노드·연결에 붙는다.
- 영역 우클릭 메뉴의 "물어보기": 고르면 설명 탭 맨 아래에 입력칸이 있다.
- 망 종류 바꾸기·확인 단추를 설명 탭에 두기.
- 영역 바탕 누르기로 고르기.
