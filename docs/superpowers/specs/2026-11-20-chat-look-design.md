# 대화창 모양 정리 (짧은 설계)

2026-11-20 · 사용자 승인 · 시안: `.superpowers/brainstorm/655-1795154234/content/chat-look-v2.html` (main 폴더, git 밖)

## 왜

- 대화창에서 내 말과 InfraSketch 답이 한눈에 갈리지 않는다.
  - 내 말풍선은 바탕보다 칠이 한 단만 밝다(#04090C → #182126).
  - AI 답에는 아무 틀이 없다.
- 학습 모드의 가이드 카드가 다른 카드와 같은 모양이라 눈에 띄지 않는다.

## 목표 / 하지 않는 것

- **목표**
  - 내 말과 답을 모양으로 가른다.
  - 가이드 카드를 "지금 할 일"로 띄운다.
  - 지금 디자인 규칙(DESIGN.md "살아 있는 설계도") 안에서 하되, 규칙의 빈 곳은 채운다.
- **하지 않는 것**
  - 새 색을 들이지 않는다.
  - 말풍선에 연두를 쓰지 않는다.
  - 동작·문구·레이아웃 구조는 바꾸지 않는다.
- **실패로 보는 것**
  - 흔한 채팅 앱처럼 보이는 것.
  - 한 화면에 칠한 연두 버튼이 둘이 되는 것.
  - 글자 대비가 떨어지는 것(WCAG 2.2 AA).

## 방식 (고려한 것과 고른 것)

- 규칙 안에서 고치기 vs 대화용 색을 하나 더 들이기 → 사용자가 **규칙 안**을 골랐다. 규칙 검토도 함께 하라고 했다.
- 시안 셋:
  - A: 연두 테두리 카드 + 답에 세로선
  - B: 설계도 눈금 카드 + 답을 판 위에
  - C: 연두 머리띠 카드 + 들여쓰기
- 사용자 선택: **가이드 카드는 C, 답 모양은 A**.

## 정한 것

1. **가이드 카드** (`src/ui/guide/GuideCard.tsx`, `guide.module.css`)
   - 위쪽 머리띠
     - 칠 `color-mix(in srgb, var(--accent) 12%, var(--bg-canvas))`
     - 아래 선 `color-mix(in srgb, var(--accent) 35%, var(--line-node))`
   - 머리띠 안
     - 제목 「학습 · <주제> (<환경>)」을 연두 글자, 12px, 600으로 쓴다.
     - 오른쪽에 진행 점: 지난 단계 강철(`--text-secondary`), 지금 단계 길쭉한 연두, 남은 단계 `--line-node`.
     - 점은 꾸밈(`aria-hidden`)으로 둔다. 진행은 글자 「이번 단계 · n / N」로 읽힌다(R1: n = step+1).
   - 본문: 지금처럼 `--color-paper-2` 판.
   - 그 밖에 그대로 두는 것
     - 환경 미확정 상태(환경 칩)도 같은 머리띠를 쓴다. 이때 점은 없다.
     - 진행 안내용 숨은 상태 알림(`role=status`)은 그대로 둔다.
2. **내 말** (`src/ui/chat/chat.module.css` `.user`)
   - 칠은 그대로(`--bg-panel-raised`) 두고 `1px solid var(--line-node)` 테두리를 더한다.
   - 모서리를 `var(--radius-surface)`(8px)로 바꾼다. 지금 12·12·4·12px는 Same Corners Rule을 어긴다.
3. **AI 답** (`.ai` 아래 본문)
   - 머리 줄(아이콘·이름·시각) 아래의 본문·진행 카드·해설 칩·버튼 전체를 왼쪽 `1px solid var(--line-node)` 세로선 하나로 묶는다.
   - 세로선은 아이콘 가운데 아래에 오고, 본문은 이름 열에 맞춘다.
   - 일반 대화·학습 모두 같다.
4. **해설 칩** (`GuideNotes`)
   - 접힘 ▸, 펼침 ▾(굵게, 테두리 `--text-secondary`).
   - 펼친 글은 칩 아래 작은 판(`--color-paper-2`, Hairline, 6px)에 넣는다.
   - 여러 개가 펼쳐져 있으면 칩 순서대로 쌓는다. 지금의 펼침 동작이 맞는지 구현 때 확인한다.
5. **DESIGN.md**
   - One Signal Rule에 한 줄을 더한다: "'지금 할 일' 판(학습 가이드 카드)은 머리띠에 연두를 옅게(12%) 칠할 수 있다. 칠한 연두 버튼 하나 규칙은 그대로다."
   - Components에 **Chat** 항목을 새로 둔다: 내 말 = Raised Slate + Hairline Strong + 8px, AI 답 = 이름 열 + 1px 세로선, 시스템 줄 = 가운데 Muted Steel.

## 만드는 사람에게 남기는 것

- 정확한 여백·세로선 위치는 기존 `.aiHead` 격자에 맞춘다.
- 기존 jsdom 테스트가 클래스 이름이나 `n / N` 글자에 기대면 함께 고친다. E2E `guide.spec.ts`는 카드의 `2 / 12`를 찾으므로 「이번 단계 · 2 / 12」로 맞춘다.
- 확인 방법
  - `npm test`, `npm run lint`, `npx tsc --noEmit`
  - E2E guide와 대화 관련 spec
  - 가능하면 화면을 띄워 눈으로 확인한다. impeccable detect가 있으면 대비·모서리 규칙을 점검한다.
