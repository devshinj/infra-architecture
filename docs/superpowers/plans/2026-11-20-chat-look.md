# 대화창 모양 정리 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 내 말과 InfraSketch 답을 모양으로 가르고, 학습 가이드 카드를 연두 머리띠로 띄운다. 디자인 규칙 안에서 한다.

**Architecture:** CSS 모듈(`chat.module.css`, `guide.module.css`)과 `GuideCard`·`GuideNotes` 마크업을 조금 고친다. 동작·데이터는 그대로 두고, DESIGN.md 에 규칙 두 줄을 더한다.

**Tech Stack:** Next.js 15, React 19, CSS Modules, Vitest(jsdom), Playwright.

**Spec:** `docs/superpowers/specs/2026-11-20-chat-look-design.md`

## Global Constraints

- 색은 토큰만 쓴다(Token-Only Rule). 새 색 토큰을 만들지 않는다.
- 연두는 가이드 카드 머리띠와 기존 보내기 버튼에만 쓴다. 말풍선에는 쓰지 않는다.
- 모서리는 `--radius-control`(6px), `--radius-surface`(8px), `--radius-pill` 만 쓴다.
- 글자는 12px 이상이고 WCAG 2.2 AA 대비를 지킨다. 그림자와 그라데이션은 쓰지 않는다.
- 커밋 메시지: `feat(ui): …` 한국어, 끝에 `Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>`.

## Review Focus

1. **환경 미확정 카드**(env null): 머리띠는 보이고 점은 없어야 한다 → Task 2 `env-less card shows the band without progress dots`.
2. **마지막 단계·완료 직전**(step = total-1): 점 개수와 지금 점 위치가 맞아야 한다 → Task 2 `dots mark done, now and todo steps`.
3. **긴 제목·좁은 패널**(320px): 머리띠 제목이 줄바꿈되고 점이 넘치지 않아야 한다. 점 줄은 `flex: none`, 제목은 `min-width: 0; overflow-wrap: anywhere` → Task 2 CSS 검사.
4. **AI 답에 진행 카드·결과 칩·버튼이 함께 있을 때**: 세로선 하나로 이어져야 한다(`.aiBody` 한 곳에만 선) → Task 1 CSS 검사.
5. **보조기기**: 점은 읽히지 않고 「이번 단계 · n / N」만 읽혀야 한다 → Task 2 `progress dots are hidden from assistive tech`.

**Files:**

- Test: `tests/unit/chatStyles.test.ts` (새 파일, CSS 글을 읽어 검사 — `tests/unit/tokens.test.ts` 와 같은 방식)

- [ ] **Step 1: 실패하는 테스트**
  ```ts
  test("my message bubble uses a surface corner and a hairline border", () => {
    const user = rule(css, ".user");
    expect(user).toContain("border-radius: var(--radius-surface)");
    expect(user).toMatch(/border:\s*1px solid var\(--line-node\)/);
    expect(user).not.toMatch(/12px 12px 4px/);
  });
  test("the AI answer body hangs on one left rail", () => {
    expect(rule(css, ".aiBody")).toMatch(/border-left:\s*1px solid var\(--line-node\)/);
  });
  ```
  `rule(css, selector)` 는 그 선택자의 첫 규칙 블록 글을 돌려주는 작은 도우미이고, 이 테스트 파일 안에 둔다.
- [ ] **Step 2:** `npx vitest run tests/unit/chatStyles.test.ts` → FAIL.
- [ ] **Step 3: CSS 를 고친다.**
  - `.user`: `border: 1px solid var(--line-node); border-radius: var(--radius-surface);` 로 바꾼다. 위 주석도 바꾼다.
  - `.aiBody`: 아이콘(20px) 가운데 아래에 세로선이 오게 한다(`margin-left: 9px; padding-left: 18px; border-left: 1px solid var(--line-node)`). 본문 시작은 지금처럼 이름 열(28px)에 맞춘다.
- [ ] **Step 4: DESIGN.md 에 `### Chat` 을 더한다.** 넣을 내용(한 줄씩): 내 말 = Raised Slate + Hairline Strong + Surface 8px, 오른쪽. AI 답 = 머리 줄(IS·이름·시각) 아래 본문 전체가 1px Hairline Strong 세로선 하나에 매달린다. 시스템 줄 = 가운데 Muted Steel 12px. 말풍선에 연두는 쓰지 않는다.
- [ ] **Step 5:** 같은 테스트 PASS. 이어서 `npm test` PASS.
- [ ] **Step 6:** 커밋 `feat(ui): 내 말풍선에 테두리와 8px 모서리, AI 답을 세로선 하나로 묶는다`.

### Task 2: 가이드 카드 연두 머리띠와 진행 점, 해설 칩 정리

**Files:**
- Modify: `src/ui/guide/GuideCard.tsx`, `src/ui/guide/GuideNotes.tsx`, `src/ui/guide/guide.module.css`, `DESIGN.md` (One Signal Rule 에 한 줄)
- Test: `tests/unit/GuideCard.test.tsx`, `tests/unit/GuideNotes.test.tsx`(있으면 거기, 없으면 GuideCard 테스트 파일에)

**Interfaces:** `GuideView`(`src/domain/guides/view.ts`) — `step` 은 끝낸 단계 수이고 화면 번호는 `step+1`(R1). 기존 `stepCount(view)` 를 쓴다.

- [ ] **Step 1: 실패하는 테스트** (GuideCard 테스트의 기존 view 도우미 사용)
  - `the band shows the topic title`
    - 머리띠 안에 `학습 · 대형 쇼핑몰 (온프레미스)` 가 있다. 제목 구분자를 `:` 에서 `·` 로 바꾼다.
  - `dots mark done, now and todo steps`
    - step 2, total 12 이면 점이 12개다.
    - `data-state="done"` 이 2개, `"now"` 가 1개(3번째), `"todo"` 가 9개다.
  - `progress dots are hidden from assistive tech`
    - 점 줄에 `aria-hidden="true"` 가 있다.
    - 카드 글에 `이번 단계 · 3 / 12` 가 있다.
  - `env-less card shows the band without progress dots`
    - env null 이면 머리띠 제목은 있고 점은 0개다.
  - GuideNotes: `an open note sits in a panel under the chips`
    - 칩을 누르면 펼친 글 요소가 `noteText` 판 클래스를 가지고 보인다.
    - 그 칩은 `aria-expanded="true"` 다.
- [ ] **Step 2:** `npx vitest run tests/unit/GuideCard.test.tsx` → FAIL.
- [ ] **Step 3: 마크업과 CSS 를 고친다.**
  - **머리띠** `.band`
    - `display:flex; justify-content:space-between; align-items:center; gap:12px; padding:8px 12px;`
    - 칠은 `color-mix(in srgb, var(--accent) 12%, var(--bg-canvas))`, 아래 선은 `1px solid color-mix(in srgb, var(--accent) 35%, var(--line-node))`.
    - 제목 `.bandTitle`: 12px, 600, `color: var(--accent)`, `min-width:0; overflow-wrap:anywhere`.
    - 점 줄 `.dots`: `flex:none; display:flex; gap:4px`.
    - 점: 6px 원. 지난 단계는 `--text-secondary`, 지금 단계는 너비 14px 연두, 남은 단계는 `--line-node`.
  - **카드**: 바깥 테두리는 `--line-node` 를 그대로 쓰고 `overflow:hidden` 을 둔다. 본문을 감싼 판은 `--color-paper-2` 이고 여백은 12px 다.
  - **「이번 단계」 줄**: 지금 `cardHead` 의 `n / N` 대신 `dt` 를 `이번 단계 · {n} / {total}` 로 쓴다. 숨은 「단계 」 글자는 지운다.
  - **해설 칩**
    - 펼친 칩은 `aria-expanded` 를 그대로 쓰고 ▾, 굵게.
    - `.noteText` 는 `padding:6px 10px; background: var(--color-paper-2); border:1px solid var(--line-shell); border-radius: var(--radius-control); font-size:12px`.
- [ ] **Step 4: DESIGN.md · One Signal Rule 뒤에 한 줄을 더한다.** 넣을 문장: "'지금 할 일' 판(학습 가이드 카드)은 머리띠에 연두를 옅게(12%) 칠하고 제목을 연두로 쓸 수 있다. 칠한 연두 버튼 하나 규칙은 그대로다."
- [ ] **Step 5: 테스트를 돌린다.**
  - 같은 테스트가 PASS 해야 한다.
  - `npm test` 가 PASS 해야 한다. "학습:" 이나 `n / N` 글자에 기대는 다른 jsdom 테스트가 있으면 새 글자에 맞춘다.
  - `npm run lint`, `npx tsc --noEmit` 이 통과해야 한다.
  - `npx playwright test tests/e2e/guide.spec.ts` 가 PASS 해야 한다. 이 E2E 는 `2 / 12` 를 찾는데, 새 글자 안에 그대로 들어 있다.
- [ ] **Step 6:** 커밋 `feat(ui): 학습 가이드 카드에 연두 머리띠와 진행 점, 펼친 해설을 판에 담는다`.
