## 1. 가장 중요한 사실

1. **공공기관의 일률적 망분리 의무는 2026-05-01에 없어졌다.** 국정원 지침이 「국가 사이버보안 기본지침」으로 바뀌면서 내부망·인터넷망 분리 조문이 삭제되고 N²SF(국가 망 보안체계)가 들어갔다. 지침 원문과 법무법인 해설, 언론 보도로 확인했다(01의 출처 1~4). 전환 기한이 없어 현장에는 옛 구성과 새 구성이 섞여 있다.
2. **N²SF 는 "망"이 아니라 정보 등급(기밀 C · 민감 S · 공개 O)으로 나눈다.** 등급이 다른 영역 사이는 "반드시 망연계"가 아니라 "통제 조건을 지키면 연결"이다.
3. **금융권 망분리는 조문이 그대로이고 예외만 늘고 있다.** 연구·개발, 업무망 SaaS, 보안 목적 AI·SaaS 예외가 추가됐다. "전면 해제"는 2026-07-15 추진 발표만 있고 시행 시기는 정해지지 않았다.
4. **개인정보 인터넷망 차단은 일일평균 이용자 100만 명 이상인 곳만 대상**이고 위험 분석에 따른 예외가 있다. **의료기관은 망분리를 직접 의무화한 조문을 찾지 못했다**(권고·자율).
5. **일반 기업·클라우드에서는 내부와 외부를 망연계로 잇지 않는다.** AWS·Azure·GCP·NCP 문서와 NIST 지침 모두 NAT 게이트웨이, 전용선·VPN, 방화벽·보안 그룹이 표준이다.

## 2. 지금 모델이 못 담는 것 (결정이 필요하다)

세 조사가 따로 같은 한계를 짚었다. seed 만 늘려서는 풀리지 않고 `src/domain/network.ts` 의 모양을 정해야 한다.

| # | 한계 | 지금 | 나온 제안 |
|---|---|---|---|
| 1 | **"내부↔외부 = 망연계" 기본값이 일반 기업·클라우드에서 틀린다.** 망연계가 필요한 이유는 "외부라서"가 아니라 "그 망이 분리 대상이라서"다. | 등급 짝 한 줄 | A 예외 규칙만 추가 / B 구성도마다 적용 기준(공공·금융·일반) / C 망 종류에 "망분리 대상" 속성. 조사는 C 를 권했다. |
| 2 | **방향이 없다.** 제어망→업무망은 되고 반대는 안 되는 일방향 전송(CDS)을 담을 자리가 없다. | `a`,`b` 무방향 짝 | 규칙에 방향 칸을 두거나, `method` 에 "일방향 전송"을 더하거나, `note` 에 글로 적기 |
| 3 | **정보 민감도 축이 없다.** N²SF 의 C/S/O 는 망 위치(폐쇄·내부·경계·외부)와 다른 축이다. 위치는 외부인데 등급은 민감(S)인 클라우드 영역이 생긴다. | `grade` 하나 | 망 종류에 `n2sf`(C·S·O·없음) 칸 추가 |
| 4 | **"직접 연결"이 없다.** 서버팜↔스토리지망, 서비스망↔백업망은 방화벽도 망연계도 아니다. | `method` 세 값 | `method` 에 "직접 연결" 추가 |
| 5 | **"폐쇄"가 두 뜻이다.** 인터넷과만 분리된 망(금융 전산센터: 대외기관과는 포트 제한으로 연결)과 어디와도 잇지 않는 망(하트비트). | `closed` 하나, 모두와 "잇지 않음" | 등급을 나누거나 짝 규칙으로 보정 |
| 6 | **조건에 따라 답이 달라진다.** 같은 두 망이라도 다루는 정보, 목적, 기관 규모로 달라진다. | 표현 불가 | 모델에 넣지 않고 `note` 와 "예상" 표시로 안내(제안) |

## 3. 넣을 수 있는 데이터

- **망 종류**: 세 조사를 합치면 약 60개 후보다(겹치는 것 정리 전). 공공 14, 금융·의료·제어·IDC 27, 기업·클라우드 20. "금융 전산망"은 전산센터 내부망·운영 단말망·업무망·대외계·연구·개발망·DR 로 쪼개자는 제안이 있다.
- **짝 규칙**: 등급 기본값과 다른 경우 56건 후보. 2절의 결정에 따라 대부분 다시 써야 한다.
- **용어**: 317개 후보(망·보안 74 + 시스템 소프트웨어·하드웨어·현업 243). 기존 50개와 겹치지 않게 썼고, 기존 노드 종류 가운데 사전에 설명이 없던 17개를 채운다. "망연계 솔루션"은 03 의 망연계 항목이 맡는다.

## 4. 근거가 약한 것

seed 에 넣기 전에 걸러야 한다. 자세한 목록은 각 파일의 5절에 있다.

- **원문을 못 본 것**: N²SF 가이드라인 1.0 본문, 국방 훈령, 교육부 지침, 클라우드 보안인증 고시 현행 조문, 금융 시행세칙 별표 7, 제어망 국내 지침(KISA 상세가이드, 과기정통부 보호지침), PCI DSS 요건 번호, 제로트러스트 가이드라인 2.0.
- **관행 수준인 것**: IDC 망 구분, 의료장비망, 콜센터망, 금융공동망, 금융 SI 용어(계정계·대외계·MCI·FEP).
- **용어 74개 중 27개**는 공식 정의를 찾지 못해 2차 자료로 쓴 초안이다(망분리·망연계·SBC·NGFW·ZTNA·SOAR·EDR·DRM·GSLB 등).
- **용어 243개**는 출처 대부분이 검색 발췌나 공식 주소만 적은 수준이다. 파일에 열람 수준([열람]·[검색확인]·[주소만])을 표시했다.
- **예고만 된 것**: 클라우드 보안인증 등급제 개편(이르면 2027 하반기), 금융 망분리 전면 해제.
- **엇갈리는 것**: N²SF 통제 항목 수, 실태평가 반영 시점, 군 작전망 이름.

## 5. 넣을 때 정해야 하는 것

1. 2절의 모델 결정(특히 1번).
2. 용어를 얼마나 넣을지: 근거 약한 항목, 지원이 끝난 제품(CentOS·HP-UX·Solaris), 국내 업체 제품, 하드웨어 항목, 짝 항목(RAID 0~10, DR 사이트 4종)을 낱개로 둘지.
3. 이름이 겹치는 별칭 정리: KVM / KVM 스위치, PM, Tmax, API Gateway, L4, SSO(03 과 04 양쪽에 있음).
4. 이미 쓰고 있는 계정: 지금은 처음 쓸 때 한 번만 복사한다. seed 를 늘려도 기존 계정에는 안 들어가므로 채워 넣는 단계가 따로 필요하다.
5. 규정이 바뀌는 속도가 빠르다. 망 지식 화면의 "예상이며 기관 규정 확인 필요" 안내는 그대로 두고, 날짜가 들어간 설명은 피한다.

## 6. 반영 현황 (2026-11-11, feat/knowledge-seed)

**모델** (2절의 1번·4번만 반영)
- 망 종류에 `separated`(망분리 대상) 속성을 더했다. 내부↔외부는 둘 중 하나가 망분리 대상일 때만 망연계, 아니면 방화벽이다.
- 연결 방식에 `direct`(직접 연결)를 더했다.
- 기본 제공 짝 규칙(`NETWORK_RULE_SEED`)을 뒀다. 차례는 기관 규칙 → 기본 제공 짝 규칙 → 등급 규칙이다.
- 2번(방향)·3번(C/S/O)·5번(폐쇄의 두 뜻)·6번(조건)은 모델에 넣지 않았다. 필요한 말은 짝 규칙의 까닭(note)과 종류 설명에 글로 적었다.

**망 지식 seed** (`src/domain/network-seed.ts`)
- 망 종류 13개 → 55개, 기본 제공 짝 규칙 0건 → 31건.
- 뺀 것: 전장망·외교정보통신망(쓸 일이 드묾), 의료장비망·의료 대외 연계 구간·금융 콜센터망·금융 개발망(관행 수준이거나 근거 미확인), 인그레스 VPC(이그레스·검사 VPC 와 겹침). "금융 인터넷망"·"금융 DMZ"는 따로 두지 않고 기존 인터넷망·DMZ 를 쓴다.
- 조사 간에 답이 엇갈린 제어망↔업무망(01 은 잇지 않음, 02 는 일방향 전송)은 규칙을 두지 않아 등급 기본값(잇지 않음)을 따른다.

**용어 사전 seed** (`src/domain/glossary-seed-extra.ts`)
- 50개 → 147개(2차분 97개). 보조 출처(위키·블로그·언론)만 있거나 "미확인"·근거 없음으로 표시된 항목은 뺐다.
- 예외로 넣은 것: 이 도구의 노드 종류를 설명하는 말 14개(웹 클라이언트, 관계형 DB 등)와 망분리·망연계·오브젝트 스토리지·파일 스토리지. 노드 종류와 망 지식 화면의 핵심어라 공식 정의 문구가 없어도 넣었다.
- 아직 안 넣은 것(약 220개): 하드웨어 43개 전부(RAID·SAN·UPS 등, 문서로 대조한 근거가 없음), 이중화·DR·백업 개념, 금융 SI 용어(계정계·대외계·MCI·FEP), 클라우드 관리형 서비스 이름(EC2·RDS 등), 근거가 약한 망·보안 용어 27개(NGFW·ZTNA·EDR·GSLB 등). 출처를 확인하면 3차분으로 넣는다.

**이미 쓰던 계정**
- 망 종류: 없는 기본 제공 종류를 넣고, 사용자가 고치지 않은 기본 제공 종류는 새 기본값으로 맞춘다. 고친 것·숨긴 것은 그대로다.
- 용어: 묶음(1차분·2차분)마다 한 번씩 넣는다. 넣은 뒤 지운 항목은 다시 생기지 않는다.
- 마이그레이션(0009): 이미 있던 내부 등급 망은 망분리 대상으로 두어 예전 동작(외부와 망연계)을 지킨다.
