# 현장 기기 · 영상 관제 · 실시간 통신 · AI 결합 구성 지식 리서치 (2026-11-12)

웹 서비스 인프라(클라이언트 → 방화벽 → 서버 → DB)만 알던 모델에 네 분야를 더하려고 조사했다.

| 글자 | 분야 | 구성 지식 | 용어 후보 |
|---|---|---|---|
| A | BLE · IoT 기기 통신 | `out-A.md` | `out-A.json` (60개, 확인 58) |
| B | CCTV · 영상 관제(VMS · VLM 분석) | `out-B.md` | `out-B.json` (60개, 확인 48) |
| C | WebRTC 실시간 영상 · 음성 | `out-C.md` | `out-C.json` (60개, 확인 57) |

각 md 는 전형 구성, 구성요소, 망·보안 관점, 그리기 지침 후보, 확인하지 못한 것, 출처 목록 순이다. 출처 페이지를 실제로 연 것만 "확인됨"으로 적었다.

## 핵심 사실

- **BLE·Zigbee·NFC 는 IP 망을 거치지 않는다.** 앱 ↔ 기기 BLE 는 망 구역·방화벽을 지나지 않는 직접 무선 연결이고, 이런 기기에서 서버로 직접 선을 그으면 틀린다(휴대폰 앱이나 게이트웨이가 중계).
- **기기 → 브로커는 기기 쪽이 먼저 거는 연결이다**(MQTT/TLS 8883, 막힌 망에서는 WebSocket 443). 클라우드 → 기기 명령·펌웨어도 그 연결 위로 내려간다.
- **지자체 통합관제센터 근거 규정**: 「지방자치단체 영상정보처리기기 통합관제센터 설치·운영에 관한 고시」(행정안전부고시 제2026-31호, 2026-05-11 제정·시행). 제3조가 "인터넷 및 업무·행정망과 분리된 단독망"을 원칙으로 하고, 다른 망과의 연계는 「국가 정보보안 기본지침」 준수 조건으로 연다. 공공기관 일률 망분리 의무가 없어진 것과 별개로 남아 있는 분리 원칙이다. 통합관제센터가 아닌 일반 CCTV 망에는 망을 나누라는 규정을 찾지 못했다.
- **VMS 에서 관제 PC 의 영상은 녹화 서버에서 직접 오고**, 카메라 접속은 녹화 서버가 건다. 외부 열람은 모바일 서버나 미디어 게이트웨이를 거친다(Milestone 문서 한 곳 기준).
- **WebRTC 는 신호 길과 미디어 길이 다른 선이다.** 신호는 HTTPS/WSS 443(TCP)으로 LB·프록시를 거치고, 미디어는 SRTP/DTLS over UDP 로 단말과 SFU·TURN 을 직접 잇는다(L7 LB·CDN 을 지나지 않음).
- **에이전트의 도구를 실행하는 쪽은 모델이 아니라 런타임이다.** 그래서 LLM 에서 MCP 서버나 사내 시스템으로 직접 선을 긋지 않는다. MCP 사양은 2026-07-28 개정판에서 상태 없는 프로토콜로 바뀌었다(요청마다 HTTP POST, 세션·서버 발신 요청 없음).

## 넣지 않은 것

- **확인하지 못한 용어 18개**: NB-IoT, 세대별 망분리, DVR, NVR, 비디오 인코더, 함체, 영상 반출, 코덱, 서브 스트림, 비디오 월, 월 컨트롤러, 영상망(용어), 스마트시티 통합플랫폼, TTA CCTV 보안 인증, DTLS, LL-HLS, 실시간 자막, NVIDIA NIM.
- **분야끼리 겹친 4개**(RTP, SRTP, SRT, HLS): 영상 관제 쪽 항목 하나만 넣었다.
- **근거를 찾지 못한 규칙**: "망분리 환경에서 실시간 미디어는 망연계 장비를 지나기 어렵다"는 국내 규정·가이드를 찾지 못해 짝 규칙으로 넣지 않았다. 미디어 서버·TURN 을 DMZ·퍼블릭 서브넷에 둔다는 것도 "공인 IP 와 UDP 로 직접 닿아야 한다"는 요건에서 끌어낸 추론이다.
- **언론 보도 수준인 것**: 국정원 지침의 영상 조항, TTA 인증, 112·119 영상 연계, N²SF 의 생성형 AI 활용 모델별 통제 요건, 홈네트워크 세대별 망분리 조문. 용어·규칙으로 쓰지 않았다.
- **방향·조건**: 일방향 전송, 보관 일수, 마스킹 같은 조건은 모델에 없어 지침·짝 규칙의 글로만 남는다.

## 주의

- VMS 구조는 Milestone 한 곳의 문서가 근거다. 포트 번호는 PDF 표를 글자로 뽑으며 열이 어긋나 문맥으로 읽었으므로 규칙·용어에 싣지 않았다.
- 고시가 쓰는 이름은 「국가 정보보안 기본지침」이고 앞선 조사(2026-11-11)의 「국가 사이버보안 기본지침」과 같은 문서인지 원문으로 확인하지 못했다.
- LLM·MCP 쪽은 변화가 빠르다. 제품 버전·성능 수치는 싣지 않았다.
